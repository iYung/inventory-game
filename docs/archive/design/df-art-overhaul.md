# Dwarf Fortress Art Overhaul

## Goal

Replace the placeholder colored-rectangle art with a Dwarf Fortress-inspired look:
near-black terminal background, chunky pixel-art PNG icons per item, and a dark
color palette for the grid, panels, and UI. All game logic is untouched — only
rendering changes.

## What changes

### PNG icons (`scripts/gen_icons.py` → `assets/images/items/`)

A Python + Pillow script generates one 32×32 PNG per item type and saves it to
`assets/images/items/<type_id>.png`. Icons are low pixel-count pixel art — each
one a recognizable silhouette of the thing it represents, drawn on a transparent
background so the dark cell behind it shows through.

| `steak` | Thick oval slab, seared brown with a darker grill-mark stripe or two |

they stay crisp when the canvas is scaled.

### Loading images (`item.lua`)

A module-level cache table `_icon_cache` maps `type_id → love.graphics.Image`.
`Item.new` loads the image once (on first use) and sets `self.sprite.image`:

```lua
local _icon_cache = {}
local function load_icon(type_id)
    if not _icon_cache[type_id] then
        local path = "assets/images/items/" .. type_id .. ".png"
        if love.filesystem.getInfo(path) then
            _icon_cache[type_id] = love.graphics.newImage(path)
        end
    end
    return _icon_cache[type_id]
end
-- in Item.new:
self.sprite.image = load_icon(type_id)
```

`Sprite:draw()` already scales `self.image` to `self.width × self.height` — no
changes needed there beyond adding the dark-bg rect (see below).

### Dark cell background (`sprite.lua`)

Before drawing the image, draw a small dark filled rect the size of the sprite.
This gives every item a consistent DF-dark tile backdrop:

```lua
love.graphics.setColor(0.08, 0.08, 0.10, 1)
love.graphics.rectangle("fill", 0, 0, self.width, self.height)
-- then draw self.image as today
```
