# Food Cart Scene Art

## Goal

Replace the flat dark stage background in the top half of the screen with Oregon Trail / Organ Trail-style pixel art that makes the player feel like they're inside a food cart looking out through a serving window at customers approaching from the street.

## Affected files

- `assets/images/scene/` — new directory for background PNG layers
- `assets/images/customer.png` — new Oregon Trail-style customer sprite
- `assets/images/merchant.png` — new Oregon Trail-style merchant sprite
- `game/scenes/kitchen_scene.lua` — draw the layered background and food-cart window frame
- `lua/game/customer.lua` — update sprite dimensions / flip logic if needed

## What changes

### Art style
Pixel art in the Oregon Trail / Organ Trail aesthetic:
- Chunky pixel silhouettes, muted earthy palette (tans, browns, muted greens/grays)
- Low-res characters (~48×72 px source drawn at 1×–2× scale), distinct dark outlines
- Characters have a hat, simple torso, and legs — the classic side-view silhouette

### Scene layout (top half, 0–360 px)

```
┌──────────────────────────────────────────────┐  y=0
│  SKY LAYER        (sky blue gradient)         │
│     (distant hills / buildings silhouette)    │
│  STREET LAYER     (cobble / dirt road)        │  y≈280
│  COUNTER/SILL     (wood plank, food items)    │  y≈320
│  WINDOW FRAME     (thick wooden border)       │  y≈340–360
└──────────────────────────────────────────────┘  y=360
```

The frame is the innermost edge of the food cart's serving window — thick wooden planks on the left, right, and bottom, creating a rectangle the customer fills when they arrive.

### Layers (drawn back-to-front)

1. **Sky** — solid muted blue, small clouds drawn as pixel rectangles
2. **Distant background** — low-resolution silhouette of buildings or trees on the horizon
3. **Street** — the cobblestone/dirt ground customers walk on
4. **Window frame** — two vertical wood-plank pillars (left/right) + a wide sill at the bottom
5. **Customer sprite** — walks along the street layer and stops center-frame

All background layers are pre-rendered as PNG files generated by a Python script (`scripts/gen_scene_art.py`) that lays pixels directly, so the art can be edited by tweaking the script and re-running it.

### Customer / Merchant sprites

New PNGs replacing the colored-rectangle placeholder:
- `assets/images/customer.png` — ~48×72 px Oregon Trail character (hat, body, legs), earthy tones
- `assets/images/merchant.png` — same proportions, different hat style / colors to distinguish from regular customer

Customer sprite is drawn at 2× scale in-engine so it reads at ~96×144 on screen (fits the existing `CW = 2*U = 72 px` width within the stage).

## What stays the same

- `config.SPLIT_Y = 360` — the grid/stage boundary does not move
- All gameplay logic (customer state machine, panels, grid) — purely visual change
- Customer walking/bob animation code — only the sprite asset changes
- HUD text (Day, Customers, $) overlays on top of the new art as before
