# Books Design

## Goal

Add a `book` item archetype and a `BookPanel` that shows an image (rather than a
grid inventory) when the book is clicked. Implement `garden_book` and
`microwave_book` as concrete books, each an extra item for their respective
programs.

## Affected files

- `lua/game/data/item_defs.lua` — add `garden_book`, `microwave_book` (+ a
  non-instantiable `book` sentinel entry)
- `lua/game/data/program_defs.lua` — add `garden_book` to `garden.extras`,
  `microwave_book` to `pump_microwave.extras`
- `lua/game/book_panel.lua` — new file: title bar + close button + centered
  image (or solid-color placeholder)
- `game/scenes/kitchen_scene.lua` — double-click / right-click to open a
  BookPanel on a `has_book_panel` item; guard nil-`item.panel` in grid helpers
- `assets/images/items/garden_book.png` — item grid icon (generated)
- `assets/images/items/microwave_book.png` — item grid icon (generated)
- `assets/images/books/garden_book.png` — panel content image (generated)
- `assets/images/books/microwave_book.png` — panel content image (generated)
- `scripts/gen_icons.py` — add `garden_book`, `microwave_book` icon generators

## What changes

### item_defs additions

```lua
book = {
    -- Sentinel only – never instantiated directly. Concrete books
    -- (garden_book, microwave_book) are separate entries that each carry
    -- has_book_panel = true and book_image.
    name = "Book",
},

garden_book = {
    name       = "Garden Book",
    footprint  = { { 0, 0 } },
    color      = { 0.30, 0.55, 0.22, 1 },   -- green, matches garden palette
    has_book_panel = true,
    book_image = "garden_book",              -- key for BookPanel image lookup
},

microwave_book = {
    name       = "Microwave Book",
    footprint  = { { 0, 0 } },
    color      = { 0.50, 0.50, 0.60, 1 },   -- steel-grey, matches microwave
    has_book_panel = true,
    book_image = "microwave_book",
},
```

### program_defs changes

`garden.extras` gains `"garden_book"`.
`pump_microwave.extras` gains `"microwave_book"`.

### BookPanel (`lua/game/book_panel.lua`)

Implements the same external interface as `ItemPanel` so it can share
`self.panels` in KitchenScene:

- `BookPanel.new(item)` — asserts `item_defs[item.type_id].has_book_panel`
- Title bar (draggable) + close button (sets `should_close`)
- Body: displays a PNG loaded from
  `assets/images/items/<book_image>.png`; if the file is absent, renders a
  solid-color rectangle as placeholder
- `should_close`, `should_leave`, `should_serve`, `should_skip` — all start
  false; `should_leave/serve/skip` are never set (books have no merchant/order
  role)
- `item.panel` is `nil` for books; BookPanel never touches it

### Image assets

Two sets of PNGs, all generated via Python/Pillow:

- **Item icons** (`assets/images/items/garden_book.png`, `microwave_book.png`):
  32×32, 3-shade rule. Garden book = open book shape in green palette; microwave
  book = open book shape in steel-grey palette. Added to `gen_icons.py`.
- **Panel content** (`assets/images/books/garden_book.png`,
  `microwave_book.png`): 160×120 placeholder art. Garden book = stylised green
  garden scene; microwave book = stylised grey kitchen scene. Generated by a new
  `scripts/gen_book_pages.py` script.

### KitchenScene changes

**Double-click / right-click to open:** `_try_double_click_open` and
`_open_container_at` both already check `def.has_panel`; extend those checks to
also trigger on `def.has_book_panel`, opening `BookPanel.new(item)` instead of
`ItemPanel.new(item)`.

**Guard nil panels in grid helpers:**

- `_all_grids()`: skip `panel.item.panel` when it is nil
- `_dragging_grid()`: only check `panel.item.panel.dragging` when
  `panel.item.panel ~= nil`

**Open/close flow:** `_open_or_focus_panel` stays unchanged — it calls
`ItemPanel.new(item)` today; a book-click bypasses that and calls
`BookPanel.new(item)` instead, then routes through the same `_open_panel` /
`_bring_to_front` path.

## What stays the same

- All existing ItemPanel logic, action buttons, merchant/order flows
- Double-click and right-click to open normal (has_panel) containers
- Books are draggable on the main grid like any other 1×1 item
- Books cannot be dropped into container panels (no panel slot to receive them
  via transfer_drag)
